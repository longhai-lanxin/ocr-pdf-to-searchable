# ocr-pdf-to-searchable

Turn a scanned/image-only PDF into a searchable PDF (original images kept + aligned invisible OCR text layer) using PyMuPDF + Tesseract on Windows. Use when a user asks to "OCR a PDF", "make a PDF searchable", or "extract text from a scanned PDF" and a proper tool like OCRmyPDF/Ghostscript is NOT installed. Handles very large books and oversized foldout pages.

## Install

```bash
git clone https://github.com/longhai-lanxin/ocr-pdf-to-searchable.git ~/.workbuddy/skills/ocr-pdf-to-searchable
```

Or copy the whole folder into your skills directory.
